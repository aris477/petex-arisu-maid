# 爱丽丝桌宠 v2.0.0 使用与升级

[下载 Windows x64 便携版](https://github.com/aris477/petex-arisu-maid/releases/tag/v2.0.0) · [完整更新日志](../CHANGELOG.md)

## 首次运行

1. 下载 `Petex-Arisu-Maid-v2.0.0-windows-x64.zip`，完整解压到可写的新目录。
2. 双击 `Start-Petex-Aris.cmd`。便携版会用同目录的 `data`，并预选 2× 高清爱丽丝。退出时在 Windows 托盘菜单选择「退出」。
3. 右键爱丽丝即可选「擦屏幕」「向左拖地」「向右拖地」或「摸头」。也可以把鼠标移到她头顶左右滑动来摸头。

右键「设置」：在「行为」里切换「随机动作气泡」，在「性格」下展开「随机动作权重」，在「显示大小」调整角色尺寸。拖到屏幕边缘后松手，会按现有贴边设置缩入屏幕边缘。

便携包是 Windows x64 版本，使用 Electron 44.3.0。应用内版本为 v2.0.0，EXE 属性页可能仍显示基础运行时的 Petex 1.1.21。校验下载文件可运行：

```powershell
Get-FileHash .\Petex-Arisu-Maid-v2.0.0-windows-x64.zip -Algorithm SHA256
```

将结果与发布页的 `SHA256SUMS.txt` 比较。

## 从旧版迁移设置

1. 退出旧版桌宠。把新版解压到独立文件夹，保留完整的旧版目录以便回退；有旧版伴随启动脚本时，迁移前先停止它自动启动旧版。
2. 如果旧版使用相同的爱丽丝角色 ID（`8a87ef6b-0a63-428c-af2a-a30448d753af`），可将旧版的 `data/settings.json` 复制到新版的 `data` 下，保留新版自带的爱丽丝图集。这个文件会迁移主宠物选择、大小、交互设置和布局；它不包含其他角色的图像。
3. 自定义角色可以按各自目录迁移到新版 `data/pets`，不要用旧版的整个 `data` 覆盖新版。如果旧版爱丽丝 ID 不同，先在设置中改选新版自带的「天童爱丽丝（女仆）」。应用会为旧设置补上新项的默认值。

旧脚本（`scripts/apply_*.py`）内含旧源码，不适用于升级到 v2.0.0。要回退，退出新版并从保留的旧目录重新启动。

## 从源码运行

需要 Windows PowerShell、Node.js 22.12 或更新版本。在完整克隆或解压的 v2.0.0 源码根目录执行以下命令，创建和使用独立的 `data`。这段操作为首次运行准备完整角色资源；已有同名角色目录或设置时会保留原文件。

```powershell
npm.cmd install
if ($LASTEXITCODE -ne 0) { throw 'npm install failed' }
$env:PEDEX_DATA_DIR = Join-Path (Get-Location).Path 'data'
$id = '8a87ef6b-0a63-428c-af2a-a30448d753af'
$pets = Join-Path $env:PEDEX_DATA_DIR 'pets'
$target = Join-Path $pets $id
New-Item -ItemType Directory -Path $pets -Force | Out-Null
if (-not (Test-Path -LiteralPath $target)) {
    Copy-Item -LiteralPath 'pets/arisu-maid-hd-2x' -Destination $target -Recurse
}
$settingsPath = Join-Path $env:PEDEX_DATA_DIR 'settings.json'
if (-not (Test-Path -LiteralPath $settingsPath)) {
    @{ petId = $id } | ConvertTo-Json | Set-Content -LiteralPath $settingsPath -Encoding ascii
}
npx.cmd --yes electron@44.3.0 .
```

设置里的通用角色导入/导出仅包含主图集。上面的完整目录还包括 `edge.webp` 和七张新版独立动作图集，需要与新版 `pet.json` 一起保留。旧 1× 角色图集仍可使用，新增动作依赖高清角色目录中的对应资源。

## 开发核验

```powershell
node tests/edge/run.cjs
```

关键入口：`app/renderer/random-action-weights.mjs` 管理权重和动作登记，`app/renderer/pet.js` 管理手动与自动动作及台词，`app/desktop.cjs` 管理拖地移动与边缘限位，`app/library.cjs` 验证角色资源，`app/renderer/cleaning-effects.js` 绘制擦屏幕特效。
