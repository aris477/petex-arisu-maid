# 爱丽丝桌宠 v2.1.0 使用与升级

[下载 Windows x64 便携版](https://github.com/aris477/petex-arisu-maid/releases/tag/v2.1.0) · [完整更新日志](../CHANGELOG.md)

## 首次运行

下载 `Petex-Arisu-Maid-v2.1.0-windows-x64.zip`，完整解压到可写的新目录，双击 `Start-Petex-Aris.cmd`。便携版使用同目录的 `data`，预置并选中 2× 高清女仆爱丽丝。退出可用 Windows 托盘菜单。

右键爱丽丝并打开「设置」。「桌面」可调大小，最大 520 px；「动作与气泡」可预览动作、展开随机动作权重；「角色库」保留添加和备份入口。预览不会改动左键点击动作。

这是 Windows x64 便携版，应用内版本为 v2.1.0，使用 Electron 44.3.0。EXE 属性可能仍显示基础运行时 Petex 1.1.21。

```powershell
Get-FileHash .\Petex-Arisu-Maid-v2.1.0-windows-x64.zip -Algorithm SHA256
```

将结果与发布页的 `SHA256SUMS.txt` 比较。

## 从旧版迁移设置

1. 退出旧版，包括可能自动启动它的伴随程序。把新版解压到独立目录，并保留旧目录用于回退。
2. 如果旧版使用相同的角色 ID（`8a87ef6b-0a63-428c-af2a-a30448d753af`），退出新版后可将旧版的 `data/settings.json` 复制到新版的 `data`。自定义角色按各自目录迁移到 `data/pets`，保留新版自带的爱丽丝图集。
3. 新包预设 `hideBuiltinMiso: true`。直接沿用不含此项的旧设置会保留 Miso；想沿用新版的单角色列表，可在退出程序后给旧设置补上该项。没有可用的导入角色时，内置角色仍可启动程序。

回退时退出新版，从保留的旧目录启动。仓库里的历史补丁脚本不适用于升级。

## 从源码运行

需要 Node.js 22.12 或更新版本。以下命令在完整的源码根目录运行，首次运行会准备角色目录，已有同名角色和设置会保留。

```powershell
npm.cmd install
if ($LASTEXITCODE -ne 0) { throw 'npm install failed' }
$env:PEDEX_DATA_DIR = Join-Path (Get-Location).Path 'data'
$id = '8a87ef6b-0a63-428c-af2a-a30448d753af'
$pets = Join-Path $env:PEDEX_DATA_DIR 'pets'
$target = Join-Path $pets $id
New-Item -ItemType Directory -Path $pets -Force | Out-Null
if (-not (Test-Path -LiteralPath $target)) {
    Copy-Item -LiteralPath 'pets/arisu-maid-hd-2x' -Destination $target -Recurse
}
$settingsPath = Join-Path $env:PEDEX_DATA_DIR 'settings.json'
if (-not (Test-Path -LiteralPath $settingsPath)) {
    @{ petId = $id; hideBuiltinMiso = $true } | ConvertTo-Json | Set-Content -LiteralPath $settingsPath -Encoding ascii
}
npx.cmd --yes electron@44.3.0 .
```

通用角色导入导出只包含主图集。完整的高清角色资料还含四边图集和独立动作，迁移时保留整个角色目录。开发核验可运行 `node tests/edge/run.cjs`。
