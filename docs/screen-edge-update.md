# 四边贴靠、台词与气泡更新

更新日期：2026-11-15。

本文记录「屏幕边缘大冒险」时期的功能。v2.0.0 用户请从 [新版使用与升级说明](v2.0.0.md) 开始；新版高清爱丽丝在贴边摸头时保留气泡和贴边画面。

## 使用

1. 先从设置导入本仓库的普通角色图集。点击「打开宠物文件夹」，关闭桌宠，将仓库 `pets/arisu-maid-hd-2x/edge.webp` 复制到已导入角色的目录，并把仓库 `pet.json` 中的 `edge` 对象合并到该目录 `pet.json`，保留原有 id 等元数据，然后重启。当前通用导入/导出仅处理普通图集，边缘图集需额外复制。
2. 设置中开启「贴边」，拖动爱丽丝到左、右、上、下任意边缘，松开后她会缩进去。
3. 开启「鼠标靠近探头」后，将鼠标移到爱丽丝附近即可探出；移远后缩回。同一条边上远处的鼠标不再阻止缩回。
4. 「定时探头」可选关闭、8 秒、15 秒、30 秒。计时从角色完全缩回与当前气泡消失两者较晚的时刻开始，因此不会把探出动画和台词显示时间算进等待。
5. 「久待台词」可设 0–120 分钟，0 表示关闭，默认 12 分钟。调整会立即应用，台词里的分钟数显示本次贴边累计时长。
6. 探头时在头顶附近左右轻晃鼠标三下，也能触发摸头摇摆和「好感度 UP」。原始 700ms 上提/旋转动作保留；下沿不会露出身体截口与边缘之间的空隙。
7. 直接把爱丽丝拖离边缘即可恢复普通状态。

本轮程序台词是文字气泡。介绍视频中的角色语音和《Pixel Time》配乐是视频素材，没有接入程序作为自动语音。

## 六组台词

共 25 句，原文位于 `app/renderer/edge-speech.js`：

| 类别 | 数量 | 触发 |
| --- | ---: | --- |
| dock | 5 | 拖入边缘、开始本次待机 |
| peek | 5 | 鼠标靠近或定时探头的真实探出 |
| stay | 5 | 贴边达到设置的久待间隔；`{mins}` 替换为累计分钟数 |
| wake | 5 | 点击唤出，是手动反馈类别 |
| toss | 3 | 较快拖甩到边缘 |
| night | 2 | 23:00–05:59 入边时优先使用 |

每次真实探头都可回复，重复的同态事件不重复播。入边台词完整显示后再接探头台词；抖动只保留一条待播探头。任务通知优先，打断入边台词后可恢复剩余时长；拖离、隐藏或退出清除待播队列。普通动作、抚摸和贴边气泡通常显示 3.2 秒，任务通知与启动问候沿用各自时长。

## 画面与实现

- 四个方向各自原画、各 32 帧；每帧 45ms，探出按对应方向的缩回帧序倒放，支持中途反向。
- 0.75 倍边缘缩放，主进程与渲染器共用 `app/renderer/edge-config.js` 的定位、遮挡线、锚点与命中范围。
- 左右终帧为 22，上下终帧为 31；保持能识别和拖动的边缘轮廓。
- 右、下、上沿保留 v3.3 原图；左沿在 2026-11-16 更新为用户确认的 GPT 补画统一版本，整张采用同一画稿，不再把新旧画面沿竖线拼接。未用镜像替代另一方向。
- 贴边气泡使用独立透明、不可聚焦、鼠标穿透窗口。普通气泡仍在人物原窗口中；贴边保留原有字号、掌机、光环爱心、女仆发箍和特殊状态标签。
- 上下沿气泡按当前帧轮廓移动并限位，最大行程按窗口大小缩放至 100 DIP。关闭、隐藏、拖离与销毁时同步收起。
- 下沿补缝在原画后延续遮挡线最后一行纹理；左沿以完整角色补图填充屏外区域，白围裙保持不透明，清除光环与发丝之间的背景。左右画面采用同一画稿与统一配色；光环和手随这张左沿母图共同运动。
- 左、下沿使用静止父层固定裁切在屏幕线。摸头保留原 700ms、上提、±3°旋转、中心支点和 ease-in-out 曲线。

## 运行、升级与验证

源码运行：安装 Node.js 后在仓库根目录运行 `npm install`，再执行 `npx electron@44.3.0 .`。源码中包含需要的角色目录，运行后按上面的普通图集导入和边缘图集复制步骤配置。仓库不包含用户数据、便携版 EXE/ASAR、制作视频或本地备份文件。

现有便携版不能通过依次运行旧补丁脚本安装本轮更新：这些脚本内含历史源码，会覆盖新实现。重新打包时必须包含本仓库整个 `app/`（包括新增模块）、保留运行时依赖及原生 unpacked 文件，并更新匹配的 EXE 内置 ASAR 完整性哈希。角色目录需同时包含最终 `edge.webp` 和带 `edge` 元数据的 `pet.json`。应先备份，关闭对应便携版进程，并保留原有用户数据和设置。

回归测试无需启动 Electron：

```powershell
node tests/edge/run.cjs
```

覆盖四边几何与拖离、角落锁定、角色附近感应区、实际缩回/气泡消失之后的等待、久待间隔开关与更改。测试报告生成于忽略的 `qa/`。

本机还验证过 Windows Electron 44.3.0、单物理显示器、150% 缩放的四边原生窗口与气泡；左、下沿摸头在 120/160/240 大小检查原动作和固定裁切。多显示器负坐标做过逻辑模拟，但未完成双物理显示器原生验收。
